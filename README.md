# ResolveU

ResolveU adalah aplikasi **Helpdesk & Ticketing IT Kampus**.

## Stack

- Expo SDK
- TypeScript
- Expo Router

Design aplikasi mengikuti `DESIGN.md` dengan Linear dark theme.

## Cara Menjalankan

```bash
npm install
npx expo start
```

## Struktur Folder

```text
app/
├── index.tsx
└── constants/
    ├── styles.ts
    └── data.ts
```
